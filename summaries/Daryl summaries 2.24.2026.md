Reflexion: Language Agents with Verbal Reinforcement Learning
This paper addresses a core limitation of current large language model (LLM)–based agents: their inability to reliably learn from past mistakes and improve through experience without expensive retraining or reinforcement learning pipelines. While LLMs can perform impressively on single-shot tasks, they often repeat the same errors across attempts in interactive or sequential environments. This limitation is important because real-world autonomy such as decision-making agents, tool-using systems, or coding assistants requires the ability to adapt behavior based on prior failures. Traditional reinforcement learning methods can enable such adaptation, but they are computationally costly, require large numbers of interactions, and are difficult to integrate with pretrained language models. The authors argue that enabling learning without updating model weights is crucial for scalable, flexible AI agents.

Prior work on LLM agents has explored combining reasoning and action, often through prompting strategies or lightweight planning frameworks. Systems such as ReAct, SayCan, WebGPT, and Toolformer integrate intermediate reasoning steps or external tools, but they generally lack a persistent mechanism for learning across episodes. Other approaches rely on fine-tuning or reinforcement learning with human feedback, which is powerful but expensive and slow. In-context learning provides some adaptability, but it is fragile and limited by context length. Overall, existing methods either do not truly “learn from experience” or require substantial computational and engineering overhead.

To address this gap, the authors propose Reflexion, a framework that enables language agents to improve via verbal self-reflection rather than parameter updates. The key insight is that language models are already strong at generating explanations, critiques, and summaries, and these capabilities can be repurposed as a learning mechanism. In Reflexion, an agent attempts a task, receives feedback from an evaluator (which may be binary success/failure, heuristic scoring, or test results), and then generates a natural language reflection describing what went wrong and how to improve. This reflection is stored in an episodic memory buffer and appended to the prompt in subsequent attempts. In effect, the agent “learns” by conditioning future behavior on explicitly articulated lessons from past failures, mimicking how humans reflect and adjust strategies.

Empirical results demonstrate that this approach yields substantial performance improvements across diverse domains, including sequential decision-making environments, multi-hop question answering, and code generation. Notably, in code generation benchmarks such as HumanEval, Reflexion significantly improves pass@1 performance by enabling the model to identify and correct logical errors across iterations. These gains are achieved without any gradient updates, highlighting the effectiveness of language-based learning signals.

However, the approach has important limitations. Reflexion depends heavily on the quality of the generated reflections; if the model produces vague, incorrect, or misleading self-critiques, performance may stagnate or degrade. Memory is also constrained by context length, meaning that long-term learning across many episodes remains challenging. Additionally, there is no formal theoretical guarantee that verbal reflection will converge to optimal behavior, and designing reliable evaluators for complex or ambiguous tasks can be difficult.

Future research directions include developing more structured and long-term memory systems, improving evaluator robustness, integrating human feedback into the reflection process, and combining verbal reinforcement with lightweight parameter updates or meta-learning. Overall, the paper introduces a compelling new paradigm for learning in language agents, showing that reflection in natural language can function as an effective reinforcement signal without traditional reinforcement learning machinery.

ReAct: Synergizing Reasoning and Acting in Language Models
This paper  tackles a key limitation in how large language models (LLMs) are used for complex tasks: existing approaches typically treat reasoning (thinking through problems step-by-step) and acting (taking actions in an environment or retrieving information) as separate processes, even though effective decision making in real-world applications requires a tight interplay between the two. This separation limits the capabilities of LLMs when faced with tasks that require both abstract reasoning and interactions with external knowledge sources or environments. The problem is important because many real tasks, such as answering multi-step questions, interacting with simulators, navigating text worlds, or performing grounded web searches require not just a static reasoning trace but also dynamic interactions with observations from actions (e.g., query results, simulation feedback). Addressing this gap brings language agents closer to human-like problem solving where thinking and acting inform each other.

Prior work in this domain focused on either improving reasoning, for example via chain-of-thought prompting which elicits intermediate logical steps or improving action generation where LLMs are used to map contexts to environment-specific actions such as navigating in text games or web interfaces. These methods independently improve performance in their niches but fail to scale smoothly to tasks requiring both planning and environment interaction. Reasoning-only methods often hallucinate or propagate errors because they lack grounding in actual information, while acting-only approaches struggle to plan effectively due to the absence of internal deliberation. Other agent frameworks combine tools or retrieval, but typically still separate reasoning from acting and do not fully integrate feedback from actions into the reasoning process.

The authors propose a unified prompting framework called ReAct, which instructs an LLM to generate interleaved sequences of natural language reasoning traces and concrete actions during task execution. The key insight behind ReAct is that reasoning and action should inform one another bidirectionally: reasoning helps the model decide which actions to take in pursuit of a goal, while observations resulting from these actions provide grounded information that refines subsequent reasoning. In practice, a ReAct prompt guides the model to alternate between generating a thought (verbal reasoning) and an action (like a search query or move in a simulation), and then incorporate the resulting observation back into the context before the next reasoning step. This creates a cycle of reason → act → observe → reason that mimics human problem solving and allows the model to adjust plans dynamically in light of new evidence.

Empirical results show ReAct consistently outperforms baselines that use reasoning alone (e.g., chain-of-thought) or acting alone. On knowledge-intensive question answering tasks such as HotpotQA and fact verification like Fever, ReAct reduces hallucination and error propagation by grounding reasoning in actual search results from a simple Wikipedia API. In interactive decision tasks like ALFWorld and WebShop, ReAct achieves significantly higher success rates than imitation learning and reinforcement learning baselines using only a few in-context examples, demonstrating its ability to plan, adapt, and navigate environments.

Despite its strengths, ReAct has limitations. It relies heavily on prompt engineering to structure the reasoning–acting interplay, making performance sensitive to prompt design and example quality. The approach also assumes the availability of an external environment or information source capable of returning meaningful observations, which may not exist for all tasks. Additionally, because the model is frozen and reasoning occurs only through generated text, there is no learning across episodes, limiting adaptability without retraining or meta-learning layers. Computationally, generating long interleaved reasoning–action chains can be expensive and slow compared to simpler prompting strategies.

Future research can build on ReAct in several directions. One avenue is automated prompt synthesis or meta-learning to reduce dependency on manual example engineering and improve generalization across varied tasks. Another direction is integrating persistent memory mechanisms so that agents can learn from repeated interactions across episodes rather than starting from scratch each time. Combining ReAct with reinforcement learning or policy optimization could also enhance adaptability in dynamic environments. Finally, extending the framework to multimodal contexts where observations include images, videos, or real-world sensor data could enable truly autonomous, grounded agents.
